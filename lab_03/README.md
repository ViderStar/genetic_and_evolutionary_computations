# Лабораторная работа №3: Аппроксимация функции с помощью двухслойной нейронной сети

## Описание

Двухслойная сеть 1–S–1 (`tansig` в скрытом слое, `purelin` на выходе), реализованная с нуля на NumPy как реплика MATLAB `newff` / `train` / `sim`: нормировка `mapminmax`, инициализация Нгуена — Уидроу, алгоритмы `traingd`, `traingdm`, `traingdx`, `trainlm`, критерии останова `epochs` / `goal` / `min_grad`. Интерактивное приложение с живой мультипликацией обучения — на JavaScript и Plotly.js.

## Вариант 3

```
f(t) = (t + 1.3) · sin(0.5t + 1),   t = -7 : 0.1 : 7   (141 точка)
```

Параметры по заданию: `traingd`, `show = 50`, `lr = 0.05`, `epochs = 600`, `goal = 1e-2`.

## Результаты

| S | traingd, 600 эпох (медиана из 10) | traingdx | trainlm | Предел (trainlm до сходимости) |
|---|---|---|---|---|
| 1 | 4.08 | 1.51 | 1.50 | 1.5 |
| 2 | 2.18 | 0.78 | 0.68 | 0.68 |
| 5 | 0.048 | 0.010 (145 эп.) | 0.007 (5 эп.) | 7·10⁻⁹ |
| 10 | 0.049 | 0.010 (117 эп.) | 0.003 (3 эп.) | 2.5·10⁻⁹ |
| 20 | 0.067 | 0.010 (196 эп.) | 0.003 (1 эп.) | 1·10⁻⁹ |
| 30 | 0.096 | 0.010 (386 эп.) | 0.0009 (1 эп.) | 3·10⁻¹⁰ |

MSE на обучающей сетке. Главное:

- По заданию сеть с S = 10 даёт MSE 0.045 и R² = 0.995, но цель 1e-2 за 600 эпох `traingd` не достигается ни в одном из 60 запусков серии. Это ограничение бюджета обучения, а не архитектуры: без лимита в 600 эпох `traingd` доходит до цели за 2360–3960 эпох.
- S = 1, 2 — недообучение при любом алгоритме. Для goal = 1e-2 нужно S ≥ 3, при S ≥ 5 ошибка падает до ~10⁻⁸.
- Граница устойчивости `traingd`: lr = 0.2 сходится, при lr ≥ 0.25 обучение расходится. Это совпадает с теоретической оценкой 2/λmax ≈ 0.19. Гессиан плохо обусловлен (κ ~ 10¹¹), поэтому `traingd` медленный.
- На данных с шумом σ = 0.7 при S = 30 сеть переобучается: MSE относительно истинной функции равна 4.06. Лучшее число нейронов — S = 3 (MSE 0.06), ранний останов улучшает S = 30 в 11 раз.

## Интерактивное приложение

`app/nn_trainer.html` открывается в браузере (Plotly.js загружается с CDN, нужен интернет). В нём есть:

- ползунок числа нейронов 1–30;
- ввод lr в диапазоне [0.01; 0.5] и goal в диапазоне [1e-4; 1e-1], а также epochs, show, алгоритма и seed;
- кривая аппроксимации, которая перерисовывается каждые `show` эпох и оставляет след прошлых положений;
- график ошибки, который строится точка за точкой;
- ползунок «Задержка (мс)» и кнопки «Старт / Пауза / Сброс» (клавиши Пробел и R);
- выбор любого из 14 вариантов, график вкладов нейронов и серия S = 1, 2, 5, 10, 20, 30.

Адрес `nn_trainer.html#demo` запускает демонстрацию автоматически.

## Запуск ноутбука

Нужны пакеты `numpy`, `pandas`, `plotly`, `kaleido` (PNG для отчёта) и `jupyter`. Полный прогон занимает около 1,5 минуты на CPU.

```bash
uv run --with numpy --with pandas --with plotly --with kaleido --with jupyter jupyter nbconvert --to notebook --execute --inplace lab_03.ipynb
```

Отчёт собирается так:

```bash
cd report && latexmk -pdf main.tex
```
