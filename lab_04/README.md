# Лабораторная работа №4: Кластеризация с помощью нейронной сети Кохонена

## Описание

Самоорганизующаяся карта Кохонена (SOM) написана с нуля на NumPy по образцу MATLAB `newsom` / `train` / `sim`. Поддерживаются:

- топологии `hextop` и `gridtop` и расстояние на решётке `linkdist`;
- сетка любого размера;
- два правила обучения: гауссова окрестность (классическое правило Кохонена) и `learnsom` из MATLAB с фазами упорядочивания и подстройки.

Интерактивное приложение с мультипликацией обучения сделано на JavaScript и Plotly.js.

## Вариант 3

4 кластера с центрами (−0.5; 0.5), (0.5; 0.5), (−0.5; −0.5), (0.5; −0.5). В каждом кластере 30–50 точек с разбросом 0.10–0.15, плоскость [−1; 1]². Всего 172 точки, `seed = 3`.

## Результаты

Правило `gauss`, 200 эпох, среднее по 10 запускам:

| Сетка | Топология | QE | TE | Мёртвых нейронов |
|---|---|---|---|---|
| 1×4 | gridtop / hextop | 0.157 | 0.241 | 0 |
| 2×2 | gridtop / hextop | 0.157 | 0.000 | 0 |
| 3×3 | gridtop | 0.135 | 0.017 | 1.0 |
| 3×3 | hextop | 0.134 | 0.000 | 0 |
| 5×5 | gridtop | 0.077 | 0.108 | 3.7 |
| 5×5 | hextop | 0.076 | 0.022 | 2.9 |

QE — квантизационная ошибка, TE — топографическая.

- **Карта 2×2.** Находит центры облаков с отклонением 0.005–0.012. QE совпадает с k-means (0.157), разбиение совпадает с истинным (ARI = 1).
- **Избыточная карта 5×5.** Нейроны распределяются внутри облаков пропорционально числу точек: около 6 нейронов на облако из 46–48 точек и 3.4 на облако из 31 точки. В среднем 3–4 нейрона остаются между облаками; на U-матрице они показывают границы кластеров.
- **Топология.** `hextop` сохраняет порядок нейронов в 5 раз лучше `gridtop`: TE на карте 5×5 равна 0.022 против 0.108.
- **Параметр `tune_nd`.** В `newsom` с MATLAB-значением по умолчанию `tune_nd = 1` центроиды карты 2×2 стягиваются к центру плоскости: QE равна 0.38–0.46.
- **Число эпох.** Карте достаточно 20–50 эпох, чтобы упорядочиться. После 100 эпох QE почти не меняется.

## Интерактивное приложение

`app/som_trainer.html` открывается в браузере; Plotly.js загружается с CDN. Приложение также встроено в раздел 8 ноутбука. В нём можно:

- выбрать топологию `hextop` / `gridtop`;
- выбрать размер сетки: 1×4, 2×2, 3×3, 4×4, 5×5 или произвольный до 10×10;
- задать число эпох и период перерисовки (10–20 эпох).

На плоскости [−1; 1]² показаны точки выборки и нейроны, соединённые линиями сетки. Скорость анимации регулируется ползунком «Задержка (мс)», процесс управляется кнопками «Старт / Пауза / Сброс» или клавишами Пробел и R.

Дополнительно доступны:

- выбор любого из 10 вариантов и генерация новой выборки;
- выбор правила обучения и способа инициализации;
- графики QE и TE по эпохам;
- карта числа точек на каждый нейрон.

Если открыть `som_trainer.html#demo`, демонстрация запустится автоматически.

## Запуск в Docker (с перезапуском ячеек)

Выполните в корне репозитория `jupyter_research`:

```bash
make up
```

После этого ноутбук доступен по адресу http://localhost:8888/lab/tree/notebooks/genetic_and_evolutionary_computations/lab_04/lab_04.ipynb. Полный прогон занимает около минуты.

Выполнить ноутбук целиком без интерфейса:

```bash
docker exec -w /workspace/notebooks/genetic_and_evolutionary_computations/lab_04 jupyter-research jupyter nbconvert --to notebook --execute --inplace lab_04.ipynb
```

Собрать отчёт (на хосте, через TinyTeX):

```bash
cd report && latexmk -pdf main.tex
```
