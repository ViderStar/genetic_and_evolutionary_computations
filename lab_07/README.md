# Лабораторная работа №7: ГА с вещественным и перестановочным представлением. Задача коммивояжёра

Работа объединяет прежние ЛР 7 и ЛР 8.

## Часть А — вещественное кодирование

Минимум функции Растригина на области [−5.12; 5.12]².

**Алгоритм:** BLX-0.5, гауссова мутация с убывающим шагом, турнирная селекция, 2 элитные особи.

**Результаты:**

- глобальный минимум найден с машинной точностью (f = 0) за 150 поколений;
- без мутации или со слишком малым её шагом 20–30 % запусков застревают в локальном минимуме f ≈ 0.99;
- на функции Шаффера F7 вещественный ГА доходит до f ≈ 10⁻⁸, а бинарный из ЛР 6 упирается в предел сетки 0.020.

## Часть Б — задача коммивояжёра (eil76, вариант 3 — циклический кроссинговер CX)

**Данные.** `data/eil76.tsp` — эталонный набор TSPLIB, `data/eil76.opt.tour` — оптимальный тур длиной 538. В прежнем файле координаты городов 59–76 были неверными, файл заменён.

**Результаты:**

| Метод | Длина тура |
|---|---|
| ГА: CX + swap, 150 × 500 | 772–847 (медиана +52 % к оптимуму) |
| Мультистарт 2-opt без ГА за то же время | 540–553 |
| Меметический ГА: CX + инверсия + 2-opt | **538 (оптимум) в 5 запусках из 5**, около 5 с |

CX сохраняет позиции городов, но не рёбра маршрута. Поэтому без локального поиска он сходится медленно.
