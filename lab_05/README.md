# Лабораторная работа №5: Поиск экстремума функции одной переменной с помощью ГА с бинарным представлением

Вариант 3: максимум `f(t) = (t − 1.3)·sin(0.5πt + 1)` на отрезке `t ∈ [0; 7]`.

## Алгоритм

Простой генетический алгоритм (NumPy, векторизованный):

- бинарное кодирование, L = 20 бит;
- рулетка со сдвигом приспособленности;
- одноточечный кроссинговер, Pc = 0.85;
- побитовая мутация, Pm = 0.01;
- элитизм;
- N = 60, 200 поколений.

## Результаты

- **Эталон.** Максимум, найденный численно: t* = 4.488826, f* = 3.127117.
- **Точность.** ГА находит t с погрешностью 9·10⁻⁷ — это предел 20-битного кода. Окрестности 10⁻³ он достигает к 7-му поколению.
- **Надёжность.** Успешны 47 из 50 запусков, медиана — 11 поколений. Три неудачи — остановка на плоской вершине: вблизи неё рулетка почти не различает особей.
- **Параметры (30 запусков на значение):**
  - N = 10 → 27 % успехов, N = 100 → 100 %;
  - при L = 8 попадание в окрестность 10⁻³ невозможно в принципе: шаг сетки 0.027;
  - без мутации — 50 % успехов, при Pm = 0.05 — 100 %.
