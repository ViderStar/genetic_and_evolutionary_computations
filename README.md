## Запуск

Ноутбуки выполняются в Docker-окружении репозитория `jupyter_research` (в корне — `make up`), JupyterLab открывается на http://localhost:8888. Без интерфейса:

```bash
docker exec -w /workspace/notebooks/genetic_and_evolutionary_computations/lab_05 jupyter-research jupyter nbconvert --to notebook --execute --inplace lab_05.ipynb
```

Отчёты собираются в папке `report/` любой лабораторной:

```bash
latexmk -pdf main.tex
```
