# Лабораторная работа №6: Поиск экстремума функции двух переменных с помощью ГА с бинарным представлением

Вариант 3: минимум функции Шаффера F7 на области x ∈ [−100; 100]². Операторы варианта — однородный кроссинговер и инверсия.

## Алгоритм

- бинарное кодирование, 2 × 20 бит;
- турнирная селекция, k = 3;
- однородный кроссинговер, Pc = 0.85;
- инверсия, Pinv = 0.2, вместе с побитовой мутацией 1/2L;
- сокращение популяции: элитарное (μ+λ), чистая замена или случайная замена;
- N = 80.

## Результаты

- **Предел точности.** Ноль не представим 20-битным кодом, поэтому минимальное достижимое значение f = 0.0200. ГА выходит ровно на этот предел.
- **Надёжность (20 запусков).** f < 0.1 — в 100 % запусков, предел сетки — в 90 %. Медиана — 26 поколений.
- **Операторы мутации.** Одна инверсия слаба: 70 % успехов, до предела доходят 10 % запусков. Она переставляет биты, но не создаёт новых значений. Без мутации успешны лишь 5 % запусков.
- **Сокращение популяции** (поколений до f < 0.1 / доля запусков, дошедших до предела):
  - элитарное — 26 / 90 %;
  - чистая замена — 44 / 65 %;
  - случайная замена — 84 / 35 %.
